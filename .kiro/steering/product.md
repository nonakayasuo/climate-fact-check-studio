# プロダクト概要

**Climate Fact-Check Studio** は、日本語の気候変動報道（新聞記事・Web記事・SNS投稿・見出し）を編集者がチェックする際に、AI が主張抽出・リスク判定・根拠候補提示・編集メモ生成までを一画面で支援する **研究プロトタイプ** です。最終目標は「編集現場で実用に耐える支援基盤」ですが、現フェーズはルールベースで MVP を回し、人間評価ログを蓄積する段階にあります。

## 中核となる能力

- **主張抽出**: 入力本文から検証対象になり得る文を機械的に切り出す（現状は語彙マッチによるルールベース、将来は OpenAI API 化）。
- **リスク判定**: 「断定が強い」「気象と気候の混同」「根拠不足」「政策的主張と科学的事実の混在」など、気候報道特有の誤読リスクを検知する。
- **根拠候補の提示**: トピックと本文に応じて、IPCC・気象庁・環境省・国立環境研究所など権威ある一次情報源を優先表示する（`data/evidence-sources.ts` がカタログ）。
- **編集者向けメモ生成**: 抽出した主張・リスク・根拠を統合し、書き換え方針まで含む日本語メモを自動生成する。
- **人間評価と監査ログ**: 5 段階評価（正確性・有用性・信頼性）と修正テキスト・修正理由タグを記録し、CSV エクスポートで研究データ化する。

## 主な利用シーン

- **報道編集ワークフロー**: 記者・編集者が出稿前に気候関連表現の妥当性をチェックし、適切な根拠資料へリンクできるようにする。
- **メディア研究**: AI 支援による編集判断の変化を、評価ログ・修正理由タグ・CSV 出力を通じて定量・定性の両面から分析する。
- **AI 支援設計の試行**: ルールベース → LLM への置き換えや、根拠 RAG・A/B 比較といった改善施策を、同じ評価フォーマットで継続検証する。

## 価値提案

- **日本語・日本ドメインに特化**: トピック分類（猛暑／豪雨／脱炭素／再エネ／原発／気候政策）、根拠ソース、リスク観点が日本の気候報道文脈に合わせて設計されている。
- **編集判断と研究記録が同居**: 単なる解析ツールではなく、人間の最終判断と修正理由が常にデータ化されるため、AI 出力の有用性そのものを評価できる。
- **段階導入を前提とした設計**: ルールベース版で UI と評価フローを固め、LLM・Supabase・RAG への置換は後段で差し替えやすい構造（`lib/analysis.ts` の純粋関数化、Supabase スキーマ草案の同梱）になっている。
