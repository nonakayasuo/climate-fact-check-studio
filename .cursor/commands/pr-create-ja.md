# PR Create JA

レビュアーが短時間で判断できるように、Pull Request を日本語で作成するためのコマンド。

## 使い方

`/pr-create-ja [base-branch]`

- `base-branch` 省略時は `main`

## 実行手順

1. 変更内容を確認する  
   - `git status`  
   - `git diff`（staged/unstaged の両方）  
   - `git log --oneline -10`（既存の文体確認）
2. 必要なら対象ブランチを push する  
   - 追跡ブランチがなければ `git push -u origin HEAD`
3. 以下テンプレートで `gh pr create` を実行する

## PR タイトル規約

- 形式: `種別: 変更の要点`
- 例:
  - `feat: 根拠資料レジストリと簡易RAG仕様を追加`
  - `fix: 分析APIの入力検証エラー表示を改善`
  - `docs: spec連携フローの説明を更新`

## PR 本文テンプレート（レビュアー重視）

```markdown
## 背景
- なぜこの変更が必要か
- どの利用者/運用上の課題を解決するか

## 変更内容
- 主要な変更点を3〜6項目
- 変更が入った領域（UI / API / Domain / Spec など）

## レビュー観点
- レビュアーに特に見てほしいポイント
- 判断が分かれそうな設計・仕様上の論点

## 影響範囲
- 影響する機能・画面・API
- 互換性リスク（破壊的変更の有無）

## テスト/確認
- [ ] ローカルで再現確認
- [ ] 型チェック/ビルド
- [ ] 主要シナリオの手動確認

## リスクとフォローアップ
- 残課題、既知の制約
- 追って対応する項目（あれば）
```

## 実行コマンド例

```bash
gh pr create --base main --title "feat: 変更要約" --body "$(cat <<'EOF'
## 背景
- ...

## 変更内容
- ...

## レビュー観点
- ...

## 影響範囲
- ...

## テスト/確認
- [ ] ...

## リスクとフォローアップ
- ...
EOF
)"
```
